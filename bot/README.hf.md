# Summary AI Bot 📄⚡

Upload a PDF → instant AI summary, key topics, and a chat that answers **only from your document** with page citations.

**Stack:** FastAPI · FAISS · MiniLM embeddings · OpenRouter (free models) · vanilla JS frontend.

See `README.md` for features and API. Configure `OPENROUTER_API_KEY` as a Space **secret** after deploying.
